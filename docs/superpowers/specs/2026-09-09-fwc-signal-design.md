# FWC-Signal：面向严格域泛化的特征价值组合设计

**状态：已完成需求确认，待用户审阅；尚未实现。**

## 1. 目的与边界

本设计在 `AGG_FWC` 中以原始 AGG 为冻结特征提取器，提出一个可解释的特征价值组合（Feature-Value Combination, FWC-Signal）模块，用于旋转机械故障分类。每一个 AGG 的 512 维深度特征被视为一个“物品”；物品具有颜色、价格、格数和二维形状。系统在 3×3 九宫格中选择总价值最优的特征组合，并以软门控方式增强这些特征。

主问题是**源域训练、未知工况目标域盲测的故障分类**，而不是连续变速转换、剩余寿命预测或有标签域适应。

不改变的边界：

- 不修改上游 AGG 源码；所有新工作限于 `AGG_FWC`。
- 不使用目标域标签、目标域全局统计量、目标工况元数据，或目标域调参。
- 严格按轴承/原始记录划分，再切窗口；不能随机窗口泄露。
- 冻结 AGG 特征提取器；FWC 与分类器在冻结特征空间中工作。
- 不使用人工价格表、人工价格区间或随机价格扰动；所有物品效用均可由来源域校准数据复算。

## 2. 三阶段数据流

### 阶段 A：AGG 基线预训练

仅用源工况训练原 AGG 分类器。得到特征提取器 `E(x)=z∈R^512`。此后冻结 `E`，以保证第 `i` 个特征维度的语义不在 FWC 训练期间漂移。

### 阶段 B：源域属性校准与预测器训练

对每个源工况、每个特征 `i`，只在源域校准数据上建立三个属性标签：

- 贡献度 `C_i`：屏蔽特征 `i` 后的分类性能下降；
- 稳定性 `S_i`：同一工况下，对记录/轴承分组进行 5 次重采样，计算五次贡献度标准差，再取其反向归一化；
- 冗余度 `R_i`：该特征与所有更高贡献特征的最大绝对 Pearson 相关系数。

训练低容量属性预测器 `H(z)→(Ĉ,Ŝ,Ř)`，输出维度为 `3×512`。源域训练样本继承其所属工况的属性校准标签。`H` 训练完成后冻结。

### 阶段 C：记录级 FWC 推理与分类

一条记录会包含多个窗口。先对该记录所有窗口的 `H` 输出求平均，得到一套记录级 `Ĉ、Ŝ、Ř`；只生成一套颜色、价值、格数、外置特征和九宫格布局。随后逐窗口进行分类，最后平均窗口分类概率，得到记录级故障类别。

该设计保证同一记录不会因为窗口扰动而出现互相矛盾的“物品颜色”和装箱方案。

## 3. 从特征属性到物品

### 3.1 颜色

对一条记录的 512 个特征按 `Ĉ` 降序排列；并采用固定金字塔配额：灰 154、绿 128、蓝 102、紫 67、金 41、红候选 20，合计 512。相等时按特征索引升序打破平局。

红色并非自动授予前 4%。红候选还必须满足：

`Q_i=0.5Ĉ_i+0.3Ŝ_i+0.2(1-Ř_i)≥0.80`。

不满足者降为金色，不补入新的红候选。因此红色实际比例可低于 4%，金色可因降级而多于 41 个。三个属性先以来源域校准范围归一化至 `[0,1]` 再代入 `Q`。

### 3.2 数据驱动效用与格数

物品价值不再是人工设定的“价格”，而是来源域可复算的特征效用。对归一化后的属性，定义：

`u_i=Ĉ_i·Ŝ_i·(1-Ř_i)`。

因此，一个特征只有同时具备高贡献、高稳定、低冗余时才有高效用；公式没有人工组合系数。九宫格中使用的总效用为：

`P_i=s_i·u_i`，

其中 `s_i` 是该物品占用的格数。这样较大物品要以相应的总效用来补偿其所占资源；小物品与大物品可在同一目标函数下直接比较。效用没有物理货币单位，仅用于排序、装箱和门控。

每种颜色仍只允许使用原先约定的格数集合：灰 `{1,2}`，绿 `{1,2}`，蓝 `{1,2,3,4,6}`，紫 `{1,2,4,6}`，金 `{1,2,3,4,6}`，红 `{1,2,4,6,9}`。

在每个颜色内按冗余度排序决定合法格数。灰、绿、蓝、紫、金，以及普通红色：低冗余优先更小格数。红色候选中 `u_i` 不低于该记录全部红色候选效用中位数的，定义为高效用红色；这类特征在低冗余时优先更大格数。该中位数为记录级数据驱动分界，不使用人工价格阈值。

形状为 1 格 `1×1`、2 格 `1×2`、3 格 `1×3`、4 格 `2×2`、6 格 `2×3`、9 格 `3×3`，允许旋转。红色九格由其高效用红色分层与合法格数规则决定，不再附加“单特征 100% 准确率”的旧条件。

## 4. 九宫格选择与软门控

在 3×3 网格上进行精确二维装箱：预生成每种形状的全部合法位置，并以位掩码分支定界搜索不重叠组合。主目标是最大化入箱物品的有效总价值。

红色大格物品是软优先而非硬限制：若含红色大格物品的可行方案价值不低于全局最大值的 95%，优先选择该方案；若其他多个较小物品的组合价值高出超过 5%，选择价值更高的组合。剩余平局依次按红色占格数、红色物品价值、特征索引字典序解决，以保证可复现。

未入箱特征的门控权重为 1。入箱特征的门控权重为：

`w_i=1+log(1+P_i^effective)`。

前置的常数 1 保证被选特征不会因无单位效用小于 1 而反向被抑制；对数项保留效用差异并避免数值爆炸。

## 5. 外置关键特征

使用正则化 Logistic Regression 为每个单独特征构建一维分类器。对每个源工况进行轴承分组交叉验证，得到该单特征在三个源工况上的准确率。

若一个特征满足：三源工况平均准确率至少 85%，且至少一个源工况准确率至少 95%，则它为外置关键特征。

- 所有满足条件者均外置，不只保留最高者；
- 保持自己的颜色、稳定性、冗余度、格数和数据驱动效用；
- 不占九宫格，也不参与藏品；
- 通过同样的 `1+log(1+P_i^effective)` 规则参与最终软门控与总价值。

若无特征满足条件，外置集合为空，模型正常继续运行。

## 6. 藏品：两阶段记录级推理

藏品仅可来自灰、绿、蓝、紫、金色的非外置特征；红色与外置关键特征均不能触发。

1. 使用普通价值完成第一次装箱和初始分类，令初始预测类别为 `ŷ`。
2. 对每个候选特征进行精确屏蔽：固定其他内容，将该特征置零，计算 `Δm_i=max(0,p(ŷ)-p_masked(ŷ))`。所有候选屏蔽在 GPU 上分批计算。
3. `Δm_i` 与 `Ĉ_i` 均使用来源域校准集第 5–95 百分位归一化并截断到 `[0,1]`；目标域不参与这一步。
4. 只有同时满足 `Δm_i≥0.40` 和 `Ĉ_i≥0.40` 的特征，才能计算关键度：`K_i=0.4Δm_i+0.6Ĉ_i`。
5. 最大 `K<0.65` 时无藏品；第一名 `K≥0.65` 且第二名 `<0.55` 时取一件；第一名 `≥0.65` 且第二名 `≥0.55` 时取两件。
6. 藏品倍率为 `r_i=1+9·clip((K_i-0.55)/0.45,0,1)`，并令 `P_i^effective=r_iP_i`。
7. 用更新后的价值重新精确装箱一次，然后给出最终窗口预测与记录级概率平均预测。最多执行一次重装箱，不循环触发藏品。

## 7. 验证、消融与失败处理

所有超参数、阈值、颜色配额和效用公式在目标测试前固定；HUST 或其他外部数据只做冻结后的最终测试，不能参与任何调参。

最低消融集：

1. 原 AGG；
2. AGG + 九宫格软门控；
3. 上项 + 外置关键特征；
4. 完整 FWC-Signal（含藏品）；
5. 去除红色 5% 软优先；
6. 分别去除稳定性、冗余度。

每项报告所有固定随机种子结果、均值±标准差、Macro-F1、各类 Recall/F1、混淆矩阵、记录级推理耗时、外置特征数量、红色/藏品触发率与装箱效用分布。不得只报告单次最好结果。

必要测试包括：512 维输入/输出形状、颜色配额、效用公式、合法格数、二维无重叠装箱、旋转、红色中位数分层与 5% 规则、外置排除、藏品阈值、同记录布局一致性、目标域零统计访问和可复现性。

若属性预测器无法在源域合理预测 `C/S/R`，若完整模型不稳定或低于 AGG，则如实报告为负面消融，不以目标域调参补救。

## 8. 非目标

- 不声称连续速度变换或剩余寿命预测；
- 不构建有标签目标域/无标签目标域自适应训练；
- 不在本轮实现端到端可微装箱；
- 不将该方法表述为新归一化算法。
