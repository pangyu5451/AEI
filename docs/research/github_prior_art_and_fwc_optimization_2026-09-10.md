# GitHub 相似项目审计与 FWC 优化建议

日期：2026-09-10  
范围：已连接 GitHub 的公开仓库检索；当前 `AGG_FWC` PU T2-FWC 结果复盘。  
目标：判断“特征价值映射 + 受限组合 + 可解释贡献”是否已有直接先例，并给出可审稿的下一步路线。

## 1. 检索结论

在本次检索到的公开仓库中，没有发现同时具备以下四个要素的直接同构实现：

1. 以深度特征维度作为候选单元；
2. 用贡献、稳定性、冗余共同生成单元价值；
3. 用固定 3×3 容量约束进行组合优化；
4. 用来源域统计决定有限时增益，并用于故障分类。

因此，FWC 的“受限特征分配”可以作为候选方法方向，但目前不能表述为已经被 GitHub 先例验证，也不能仅凭颜色和价格区间宣称算法创新。可发表的技术对象应改写为：

> source-only calibrated, constrained feature allocation for rotating-machinery fault classification

即：来源域校准的受限特征分配故障分类方法。

## 2. 最接近的公开项目及其操作方式

### 2.1 DG-for-RMFD：方法对比基线

仓库：[xiaoyiming1999/DG-for-RMFD](https://github.com/xiaoyiming1999/DG-for-RMFD)

操作方式：AGG 直接聚合源域训练；DANN、MMD、CORAL、Triplet loss 做域对齐；Mixup 做数据增强；MLDG 做元学习；DAEL 做集成学习。项目强调固定数据集、工况迁移和统一比较。

对当前工作的启示：

- FWC 首先必须与 AGG/ERM 在同一划分、同一标签、同一记录聚合规则下比较；
- FWC 不应同时改变主干、损失、数据划分和特征组合规则；
- 论文中应保留 AGG 作为主基线，所有 FWC 结果以配对消融方式报告。

### 2.2 VibraHybrid-FD：筛选后再解释

仓库：[tuanle311/VibraHybrid-FD](https://github.com/tuanle311/VibraHybrid-FD)

操作方式：先提取 20 个 STFT 特征和 36 个 HHT/EMD 特征，组成 56 维表格特征；再用 Boruta + Random Forest 做全相关特征筛选；最后用 XGBoost 等模型分类，并用 SHAP 做解释。

可借鉴点：

- 特征筛选和特征解释是两个阶段，不能把 SHAP 重要性直接等同于可用于训练的权重；
- 可把 FWC 的贡献度定义为遮蔽实验或模型性能下降，把 SHAP 作为辅助解释，而不是唯一依据；
- 应报告筛选前后性能、保留特征数、跨种子保留频率和计算开销。

注意：该仓库使用随机划分，不能直接作为当前 PU 严格工况/记录协议的评价标准。

### 2.3 Brusa XAI 项目：贡献分析主要是后验解释

仓库：[LGDiMaggio/Explainable-AI-for-Machine-Fault-Diagnosis](https://github.com/LGDiMaggio/Explainable-AI-for-Machine-Fault-Diagnosis)

操作方式：使用 SVM/kNN 进行故障分类，再用 SHAP 给出全局特征重要性、正确/错误样本的重要性和局部单样本解释。

可借鉴点：

- “哪个特征推动了某个类别决策”可以作为论文的可解释性结果；
- 正确样本与错误样本的特征贡献差异，适合定位外圈/健康混淆；
- 但 SHAP 本身不等于动态特征选择，也不证明改变 SHAP 权重会提升准确率。

### 2.4 CS-SHAP：按信号域解释，而不是修改模型

仓库：[ChenQian0618/CS-SHAP](https://github.com/ChenQian0618/CS-SHAP)

操作方式：对已经训练好的故障诊断网络，在时间、频率、包络、时频和循环谱域分别进行 SHAP 分析；通过域变换和后验归因解释载波频率与调制频率贡献。

可借鉴点：

- FWC 可以将“512 个深度维度的贡献”与“原始信号/频率域解释”分开报告；
- 可增加原始信号域的 Grad-CAM 或频率域归因，验证深度特征权重是否具有信号机理一致性；
- SHAP/CS-SHAP 更适合作为外部解释验证，不宜直接参与目标域调参。

### 2.5 Jayam07 项目：域适配与解释并列

仓库：[Domain-Adaptation-with-Explainable-AI-for-Deep-Learning-Based-Bearing-Fault-Diagnosis](https://github.com/Jayam07/Domain-Adaptation-with-Explainable-AI-for-Deep-Learning-Based-Bearing-Fault-Diagnosis)

操作方式：使用 1D/2D CNN，配合 MMD/CORAL 做域适配，同时使用 Grad-CAM 和 SHAP 分析决策依据。

可借鉴点：

- 解释模块可以作为独立的分析分支，不必一开始嵌入训练闭环；
- 当前 FWC 应先证明“解释稳定、来源域可复现”，再验证“权重干预是否改善分类”；
- Grad-CAM 解释的是时间区域，SHAP 解释的是输入特征，二者不能混作同一指标。

### 2.6 MCFormer：动态融合来自注意力，而不是人工价格

仓库：[sothulthorn/MCFormer](https://github.com/sothulthorn/MCFormer)

操作方式：多传感器输入经过两个 Transformer 分支，再用双向 cross-attention 融合；不同分支的 CLS 表征分别分类，最后平均 logits。

可借鉴点：

- “不同信息源/特征获得不同权重”已有注意力融合先例；
- FWC 的差异应放在可验证的“来源校准 + 受限组合决策”上，而不是仅仅再加一个 attention 层；
- 可将 MCFormer 类型动态融合作为外部基线，但不能声称其已经实现了 FWC 的 3×3 组合约束。

## 3. 对当前正式结果的诊断

当前种子 2026 的结果文件：

[metrics.json](../../results/fwc-t2-formal-2026/metrics.json)

关键现象：

- FWC Test Macro-F1 = `0.1613`；
- 原 AGG T2 基线约为 `0.8837`；
- 来源验证 Macro-F1 = `1.0`，但目标工况严重下降；
- 280 条目标记录全部触发 2 个藏品；
- 没有外置特征；
- 目标域只读取 1 次，协议审计通过，但这是论文工况迁移协议，`bearing_disjoint=False`。

这说明当前问题不是“候选特征数量不够”，而更可能是：

1. FWC 门控改变了冻结特征的数值分布，破坏了原 AGG 分类器的决策边界；
2. 藏品触发规则在目标域出现系统性过触发，导致所有记录都被二次修改；
3. 来源验证完美不能代表未见工况泛化，当前验证选择与目标工况之间存在明显错位；
4. 颜色/价格的组合策略目前还没有证明比连续、可校准的软权重更可靠。

## 4. 推荐的可审稿优化路线

### R0：基线等价性

在相同 T2 配置和种子 2026 下运行：

1. 原始 AGG/Identity；
2. 冻结 AGG 特征提取器 + 原分类器；
3. 仅加入 FWC 门控，但不训练分类器；
4. 仅加入 FWC 组合，不触发藏品。

如果第 2 项不能复现原 AGG，先修复基线一致性；如果第 3 项骤降，问题在门控数值；如果第 4 项正常而藏品版骤降，问题集中在藏品规则。

### R1：先做可解释性，不改模型

冻结原 AGG，使用来源验证记录计算：

- 遮蔽单特征后的 Macro-F1 下降；
- 目标类别置信度下降；
- 不同来源工况的贡献稳定性；
- 与高贡献特征的相关性；
- SHAP/Grad-CAM 的一致性。

输出应是“特征贡献报告”，不直接把贡献报告转换为训练门控。这样可以先获得一个稳定、可解释、风险低的论文结果。

### R2：连续软权重

在不使用颜色、格数、藏品的情况下，测试有界软权重：

\[
g_i=\operatorname{clip}(1+\lambda\,q_i, g_{\min}, g_{\max}),
\]

其中 `q_i` 由来源域贡献、稳定性和低冗余构成，`lambda` 只在来源验证集上确定。建议先设置 `g_min=0.8`、`g_max=1.2`，避免把原始特征直接压成近零；若 R2 仍明显下降，不再进入组合优化。

### R3：受限组合优化

只有 R2 不损害基线时，才启用 3×3 约束。将颜色和价格区间改为预注册的、单调的数据映射：

- 颜色：按来源训练集贡献分位数确定；
- 格数：由离散候选形状表示容量/稀疏性，而不是暗示物理价值；
- 价格：使用固定单调函数或来源训练集分位数，不能人工根据测试结果调区间；
- 组合：以总效用最大为主目标，并记录是否触发红色优先；
- 所有规则只在来源训练/验证数据上冻结。

### R4：藏品机制单独消融

藏品不是 R3 的默认组成部分，应单独比较：

- 无藏品；
- 1 个藏品；
- 2 个藏品；
- 藏品只改变软权重，不改变硬门控；
- 藏品触发阈值由来源嵌套验证确定。

当前“280/280 条目标记录触发 2 个藏品”已经是过触发预警，正式实验中必须报告触发率和按工况分布。

## 5. 当前不建议做的事情

- 不要使用目标域指标反向调颜色、价格、阈值或藏品倍数；
- 不要把 SHAP 的后验解释值直接当作训练权重而不做遮蔽验证；
- 不要在当前 FWC 结果尚未超过 AGG 前扩展到 HUST；
- 不要把当前论文工况迁移结果称为未见轴承泛化；
- 不要上传原始 PU/HUST 数据、模型检查点和虚拟环境到 GitHub。

## 6. 结论与建议主线

推荐主线为：

> AGG/ERM 基线 → 来源域特征贡献审计 → 连续有界软权重 → 3×3 受限组合 → 藏品机制作为独立消融 → 多种子与外部测试。

当前最值得优先完成的不是继续调价格区间，而是 R0 的四组定位实验。它们能直接回答 FWC 为什么从 `0.8837` 降到 `0.1613`，并决定后续是保留“受限组合”还是回退为“可解释特征贡献 + 软权重”。
